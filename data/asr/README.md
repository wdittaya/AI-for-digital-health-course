# Lab 6 test set

30 short English clips of patients describing symptoms (16 kHz mono WAV), re-sampled from the *Medical Speech, Transcription, and Intent* corpus (Paul Mooney, Kaggle; HF mirror `yashtiwari/PaulMooney-Medical-ASR-Data`). Transcribe each clip and submit `id,transcript`. Metric: word error rate (lower is better).
